# Neighborhood

An interactive, single-page Three.js visualization of a human navigating a
semantic street model. Use the on-screen toolbar (or the `M`, `T`, `S`, `A`,
and `R` keys) to move, turn, stop, avoid an obstacle, or reroute the agent.

## Run locally

The application has no build step. Serve the repository with any static HTTP
server, then open it in a modern browser:

```sh
python3 -m http.server 4173
```

Visit `http://localhost:4173`.
